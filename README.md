A single painfully honest — yet manager-safe — out-of-office auto-reply for make.fun's "The Painfully Honest Out-of-Office" bounty: one sentence that admits the inbox is a mountain and the time away is genuine recovery, and still promises a reply on Monday.

## Run it

```sh
node main.ts
```

The program writes the auto-reply to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It is deterministic: every run writes the same bytes.
